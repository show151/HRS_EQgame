# HRS EQ game

仕事のケーススタディ10問から、ソフトスキルに関する選択と参考指標を確認するWebアプリです。回答に正解・不正解はありません。各問の解説は挟まず、全10問の回答後に選択内容とグラフを表示します。結果の意味づけや自己評価は回答者本人に委ねます。

Next.js App Router、TypeScript、Tailwind CSS、Rechartsを使用しています。プレイヤー名、XP、プレイ履歴、途中の進捗、分析結果はブラウザーの`localStorage`に保存します。プロフィールは`/profile`です。

## セットアップ

Node.js 20.9以降とpnpmを用意し、プロジェクトのディレクトリで依存関係をインストールします。

```bash
pnpm install
pnpm dev
```

ブラウザーで <http://localhost:3000> を開きます。

## 型チェックと本番ビルド

```bash
pnpm typecheck
pnpm build
pnpm start
```

開発サーバーは`.next-dev`、本番ビルドは`.next`に生成物を分けて保存します。

## Geminiの回答分析を有効にする

10問を完了すると、Geminiによる回答分析を自動で開始します。APIキーが未設定、またはGeminiに接続できない場合も、選択肢の仮の重みからグラフを自動集計し、分析パネルにはデモ例を表示します。Gemini分析を有効にする場合は、プロジェクト直下に`.env.local`を作成してAPIキーを設定し、開発サーバーを再起動してください。

```dotenv
GEMINI_API_KEY=your_api_key
# 任意。未指定時は gemini-2.5-flash
GEMINI_MODEL=gemini-2.5-flash
# GOOGLE_API_KEY もキー名として使用できます
```

キーを`NEXT_PUBLIC_`付きの環境変数にしたり、ブラウザー側コードへ記載したりしないでください。10問完了時に、選択したケースと行動、およびグラフ作成用の仮の重みをGemini APIへ送り、6指標の参考グラフと、回答に記された行動パターンをケース番号つきで3つ整理します。プレイヤー名、XP、プロフィールは送りません。APIキーはサーバー側でのみ読み込みます。Geminiは他者からどう見られるか、性格・能力、回答に書かれていない動機を推測しません。結果の意味づけは回答者本人に委ねます。Geminiを利用できない場合のデモ例は回答分析ではないことを画面上に明記します。

## ゲーム仕様

- 10問、それぞれ4択のケーススタディです。
- 選択するとすぐ次のケースへ進み、途中の解説や個別振り返りは表示しません。
- 10問完了後、選んだ全行動と選択肢に設定された6つの仮の重みを参考値として可視化します。
- 1問回答で20 XP、10問完了で追加50 XPを獲得します。
- 成長グラフは実プレイ履歴とは別のデモデータです。
- プロフィールから保存データを削除できます。

表示指標は科学的な能力測定ではなく、ケースの選択肢に設定した仮の重みです。10問の選択だけから性格、他者からの見え方、選ばなかった行動を推測しません。データベースやログイン機能はなく、通常の回答データはブラウザー内に保存します。レベル称号はプレイへの取り組みを示し、能力の優劣を示しません。旧5問版のプロフィールと履歴は移行して保持します。
